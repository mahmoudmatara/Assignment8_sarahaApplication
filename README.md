# Node Modular API

Node.js + Express + MongoDB using a feature-based modules structure.

## Run

1. Copy `.env.example` to `.env` and set `MONGO_URI`.
2. Run `npm install`.
3. Run `npm run dev`.

## Routes

- GET/POST `/api/users`
- GET/PUT/DELETE `/api/users/:id`
- GET/POST `/api/products`
- GET/PUT/DELETE `/api/products/:id`
